# .gemini — GitDigital‑Solana AI OS

This repository defines the AI operating system for the GitDigital‑Solana universe.

It contains:

- System roles for Gemini agents
- Reusable prompt templates
- Multi-step workflows
- Structured schemas for governance and grants
- Model and formatting configuration

## Directories

- `system/` — Agent roles and system prompts
- `workflows/` — Multi-step AI workflows
- `prompts/` — Reusable prompt templates
- `schemas/` — JSON schemas for structured outputs
- `config/` — Model, safety, and formatting configuration

## Philosophy

`.gemini` is the coordination layer between:

- On-chain Solana programs
- Governance and grant processes
- Dashboards and transparency tools
- Community education and assets

All other GitDigital‑Solana repos can treat `.gemini` as the AI brainstem.
